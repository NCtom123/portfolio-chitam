## 🌟 Tính năng nổi bật (Key Features)

- **Giao diện Glassmorphism & Modern UI**: Thiết kế tinh tế, hiện đại với hiệu ứng Dark / Light Mode tự động lưu trạng thái.
- **Đa ngôn ngữ (Bilingual VI / EN)**: Chuyển đổi ngôn ngữ Tiếng Việt & Tiếng Anh toàn diện chỉ với 1 click.
- **Trình xem ảnh HD (Image Lightbox Modal)**: Phóng to toàn màn hình sắc nét các hình ảnh dự án và hoạt động cộng đồng, hỗ trợ điều hướng phím tắt (← / → / Esc) và cảm ứng vuốt (Swipe).
- **Hồ sơ năng lực tương tác (Interactive CV Viewer)**: Xem trực tiếp PDF trên trình duyệt hoặc tải về máy nhanh chóng.
- **Form liên hệ tích hợp**: Gửi tin nhắn liên hệ trực tiếp với thông báo Toast hiện đại.

## 🛠️ Công nghệ sử dụng (Tech Stack)

- **Frontend**: HTML5, CSS3 (Custom Properties, Flexbox, CSS Grid, Glassmorphism), JavaScript (ES6+)
- **Icons & Fonts**: Bootstrap Icons, Font Awesome, Google Fonts (Plus Jakarta Sans)
